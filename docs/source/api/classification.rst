chemotools.classification
=========================

.. currentmodule:: chemotools.classification

Classification methods for spectral data. These methods assign discrete class labels to samples based on their spectral signature.

**Import from this module:**

.. code-block:: python

   from chemotools.classification import (
       PLSDA,
   )
